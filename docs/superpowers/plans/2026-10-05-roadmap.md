# swarm50 digital-products pivot: implementation roadmap

**Spec:** `docs/superpowers/specs/2026-10-05-digital-products-pivot-design.md` (v3.2)

**How the plans are written:** the spec covers several subsystems, so it's built through 7 plans, each
producing working, tested software on its own. **Plan 1a is written in full now.** Each later plan is
written when its predecessor finishes, so it reflects the real code and real findings (K0, measured
costs) rather than guesses. Every plan follows TDD, commits once per task, and ends with the full
suite green.
